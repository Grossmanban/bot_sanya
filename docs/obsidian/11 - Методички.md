# Методички

**Обновлено:** 2026-11-17 · **Исходники:** `backend/app/manuals.py`, `backend/app/richtext.py` (санитайзер общих текстов)

## Функционал

«Админ → Методички» (owner + admin). Методичка = разделы (заголовок + HTML), версии, встроенные картинки, доступ по людям.

- **Создание**: вручную или «Загрузить HTML-файл» — готовая страница целиком (разделы по `<h2>`, без них — по `<h1>`,
  текст до первого — «Введение»). Кодировка определяется сама (UTF-8/UTF-16/CP1251/`<meta charset>`); понятные ошибки
  на пустой файл, PDF, Word, страницу без текста.
- **ТЗ 29.10**: оформление сохраняется — блоки, классы, inline-стили, таблицы, встроенные картинки и `<style>` страницы
  (`manuals.css`, `body_class`). Визуальный редактор («Визуально» — правка прямо на странице; «Код» — HTML+стили; «Предпросмотр»);
  предупреждение о несохранённых правках. Замена из HTML, переименование, удаление с подтверждением.
- Каждое сохранение — новая версия (`manual_versions`), старые остаются; номер методички, выдача и прочитанность неизменённых разделов не меняются.
- **Выдача**: «Команда → человек → Методички» по одной или «Закрыть все». Вкладка «Обучение» с «Методичками» у сотрудника —
  пока выдана хотя бы одна. Доступ сервер проверяет при каждом открытии; отозванная ссылка не работает.
- **Чтение**: оглавление с отметками, «Назад/Далее», «Раздел N из M», прогресс по человеку. Раздел прочитан, пока его
  hash не менялся; изменённый — снова непрочитан, удалённый не считается.

## Безопасность

HTML чистится на сервере по белому списку: без скриптов, фреймов, форм, обработчиков событий, `javascript:`, внешних
картинок/шрифтов/`@import`/`url()` (пиксель-трекер выдал бы читающего). Встроенные картинки — на сервере
(`manual_images`), отдаются короткими подписанными ссылками `/api/media/manualimg/{id}`. Показ — в изолированной
рамке-«песочнице» без скриптов. Наружу ничего не отправляется.
