# Telegram-бот

**Обновлено:** 2026-11-17 · **Исходники:** `backend/app/bot.py` (роутер `build_router`)

## Общее

aiogram 3, long polling, приватные чаты. Middleware `block_guard`: заблокированному (`account_state=blocked`) —
один ответ «⛔ Доступ к боту заблокирован…» на ЛЮБОЕ сообщение/кнопку (включая старые), FSM-состояние сбрасывается.
Кнопка меню чата — «Приложение» (`set_menu`, только имеющим доступ; `setup_menu_button` обновляет всем при старте).

## Команды

| Команда | Кто | Что |
|---|---|---|
| `/start [ref_…/inv_…]` | все | доступ по ссылке (см. [[09 - Рекрутинг и доступ]]): незнакомец — молчание/анкета; свой — меню |
| `/raspred_zavtra` + кнопка «📋 Распред на завтра» | персонал (`raspred`) | распред завтрашнего дня простым текстом (тренер — своя сеть) |
| `/finances` | персонал (`review`) | балансы: штрафы/бонусы/вычеты/на согласовании |
| `/pending` | персонал | «Ждут решения» — те же счётчики, что бейджи приложения |
| `/fakt 480 [ДД.ММ]` | owner | общий факт дня (принятые автоматически, аннулируемые штрафы) |
| `/archive_here` / `/archive_off` | owner (в группе) | подключить/отключить архивную группу |
| `/group_pre` / `/group_main` / `/group_off` | owner (в группе) | подключить «Предзакреп»/«Основную команду»/отключить |
| `/alice_here` / `/plus_here` | owner (в форуме) | группа фотоотчётов продукта (форум с темами, бот — админ с «Управление темами») |

## Callback-префиксы inline-кнопок

| Префикс | Действие |
|---|---|
| `reg:`, `register`, `reg_send` | заявки «Принять/Отклонить», чат-регистрация по приглашению |
| `urg:` | срочная заявка: разрешить/запретить |
| `pen:`, `pen_old:`, `sf:` | штрафы (1/3/5/своё); `sf:`/`pen_old:` — устаревшие кнопки |
| `rep:`, `repv:`, `fact:`, `factc:` | отчёт: начать/число «как план» |
| `rv:` / `ns:` | решение по отчёту (принять/исправление/штраф) и неявке (штраф/без штрафа) |
| `rsn:` | выбор шаблонной причины (кнопки фиксируются в FSM-данных на момент показа) |
| `fx:` | одобрить/отклонить штраф тренера |
| `ev:` | заявка события: подтвердить; отклонить — ссылка в приложение |
| `goal:` | «Участвую» в цели |
| `ack:` | «Я ознакомился» (прочтение рассылки) |
| `brr:` / `brs:` | «Ответить» на рассылку: сбор и отправка |
| `trc:` / `ttc:` | кандидат/тренер подтверждают обучение (у тренера — с version, старая кнопка отказывает) |
| `tcw:`/`tcc:`, `ctw:`/`ctc:` | «я написал тренеру/менеджеру» или «не могу первым» |
| `trr:` | кандидат просит перенос обучения |
| `trq:` | решение админа по запросу обучения (одобрить сразу / причина отклонения) |

## FSM-диалоги (StatesGroup)

`Registration` (фамилия+имя приглашённого) · `PenaltyInput` (сумма штрафа legacy) · `ReportInput` (объём → фото) ·
`EventReject` (причина отклонения заявки без HTTPS) · `BroadcastReply` (сбор ответа, альбомы под lock, до 10 медиа) ·
`TrainingInput` (перенос кандидата, причина отказа админа) · `DecisionInput` (единицы штрафа, причина из шаблонов/текстом).

Fallback без состояния: незнакомец — молчание + лог; pending — «на рассмотрении»; approved — меню; rejected — молчание.
