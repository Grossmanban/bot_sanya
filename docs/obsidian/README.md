# 🗂 Карта документации «Иди работай!» (bot_sanya)

> [!important] Это главная точка входа для ИИ-агентов и людей
> Telegram-бот + Mini App для графика смен, отчётов, финансов и рекрутинга.
> **Перед любой задачей — прочитать [[00 - Регламент документации|регламент]] и нужные страницы.**
> После любого изменения кода — обновить затронутые страницы. Устаревшая документация — **фатальная ошибка**.

**Актуально на:** 2026-11-17 · **Проверено по коммиту:** `78c73da` · Стек: Python 3.13 / FastAPI / aiogram 3 / SQLite / Next.js 15

## Как пользоваться

Папку `docs/obsidian/` можно открыть как отдельный vault в Obsidian (или скопировать внутрь существующего). Связи между страницами — `[[вики-ссылки]]`, у каждой страницы сверху блок «Обновлено» и исходные файлы.
