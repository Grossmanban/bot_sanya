# Настройки приложения (app_settings)

**Обновлено:** 2026-11-19 · **Исходники:** `backend/app/app_settings.py` (SCHEMA), `backend/app/templates.py` (REASON_KINDS, TEXTS), `.env` (18.11: OCR)

Хранятся в таблице `app_settings` (key→value), редактируются в «Админ → Настройки» (`GET/PATCH /api/admin/settings`,
owner+admin; ставки — только владелец). Типы: bool/time/weekday/minutes/days/lead/rub/count/ttl/choice/digest_every.

## Напоминания и задания

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `eve_reminder_enabled/time` | 1 / 20:00 | напоминание накануне смены |
| `auto_raspred_enabled/time` | 1 / 21:00 | распред на завтра админам |
| `week_reminder_enabled/weekday/time` | 1 / чт / 12:00 | «отметь следующую неделю» |
| `fact_request_enabled/delay` | 1 / 15 мин | запрос отчёта после конца смены |
| `report_reminder_enabled/lead` | 1 / 120 мин | напоминание до срока отчёта |
| `report_digest_enabled/time/to` | 1 / 22:00 / admins | вечерняя сводка (owners\|admins\|staff) |
| `weekly_report_enabled/time` | 1 / пн 10:00 | итоги недели + Excel |
| `backup_enabled/time` | 1 / 04:00 | бэкап базы владельцам |
| `training_reminder_eve_time/morning_time` | 20:00 / 08:00 | напоминания об обучении |
| `global_actual_evening/morning_enabled/time` | 1 / 21:30 · 09:30 | напоминания про факт дня |
| `show_colleague_names` | 1 | сотрудники видят имена коллег в дне (выкл — только количество) |

## Рекрутинг и стажировка

`internship_units` (20), `second_stage_units` (50), `link_ttl_minutes` (60 — срок жизни реферальной ссылки/QR),
`training_cancel_limit` (3 — порог предупреждения об отменах).

## Группы и лента

`main_team_days` (3 — «Основная команда» с этого дня), `groups_auto_invite` (1), `groups_check_time` (10:15),
`feed_hide_after_days` (7 — авто-архив целей/событий).

## Служебные уведомления (19.11, сводка — [[17 - Уведомления и планировщик]])

| Ключ | По умолчанию | Смысл |
|---|---|---|

## Служебные ключи (не редактируются вручную)

`archive_chat_id/title` (архивная группа), `alice_chat` / `plus_chat` (форумы фотоотчётов), `group_pre/main` (чаты групп),
`reports_since` (день, с которого отчёты обязательны), `last:*` (метки «не чаще N минут»).

## Шаблоны причин (reason_templates, ТЗ 28.10 §2)

Виды (`REASON_KINDS`): `fine`, `bonus`, `deduction`, `report_fine`, `no_show_fine`, `no_show_excuse`, `excuse`, `annul`,
`forgive`, `pause`, `block`, `reject_candidate`, `cancel_training`, `change_training`, `reject_request`, `alice_reject`,
`plus_reject`. Кнопки в формах и в боте; обязательность причины решает сервер. API: `GET /api/reasons`,
`GET/POST/PATCH /api/admin/reasons(/{id})`.

## Тексты сообщений бота (message_texts / TEXTS)

Редактируемые сообщения (например `candidate_trainer` — «Хорошие новости» кандидату); плейсхолдеры `{ФИО_ТРЕЕРЕ}` и т.п.
подставляет код; «Вернуть исходный» сбрасывает правку. API: `GET /api/admin/texts`, `PUT /api/admin/texts/{key}`.

## Прочие настройки-константы в коде

- `init_data_max_age` = 24 ч ([[01 - Архитектура и стек]]).
- Окно срабатывания суточных заданий 3 ч, интервал планировщика 30 с ([[17 - Уведомления и планировщик]]).
- `MAX_PHOTO` 10 МБ; видео рассылок до 50 МБ, хранение > 20 МБ на сервере.
- Медиа-ссылки — короткоживущие подписанные.
- **18.11, «Заполнить по фото»** (`.env`, не в таблице настроек): `OCR_KIND` — `opencode` (локальный
  `opencode serve --service`: сессия с картинкой, Basic-авторизация) или `openai` (любой OpenAI-совместимый API);
  `OCR_BASE_URL` (пусто — фича выключена, кнопка в мастере скрыта; из контейнера хост — `host.docker.internal`),
  `OCR_MODEL` («providerID/modelID» у opencode, напр. `opencode/nemotron-3.5-super-vl-free`; модель должна уметь
  изображения), `OCR_API_KEY` (у opencode — «opencode:пароль» из `~/.config/opencode/service.json`).
  См. [[07 - Выплаты и реквизиты]].
