# Смены и график

**Обновлено:** 2026-11-24 · **Исходники:** `backend/app/services.py` (основная бизнес-логика), `backend/app/assign.py` («Надбавка за точку», «Распределение по точкам»)

## Жизненный цикл смены

Одна строка на (user, date) среди живых (`ux_shifts_live`); отменённые остаются историей (`withdrawn/removed`).

```
(нет) --create(будущая дата)--> active
(нет) --create(на сегодня)--> awaiting_approval --админ--> active | rejected_by_admin
(нет) --pre-declare--> pre_declared_off --clear--> (нет)
active --cancel--> cancelled --restore--> restored --final cancel--> finally_cancelled
```

`cancelled` = «беру выходной» (день считается отмеченным). `finally_cancelled` создаёт черновик штрафа
`draft` в журнале финансов («ждёт суммы», см. [[06 - Финансы, ставки и вычеты]]).

## Окна редактирования (время московское, для каждой даты отдельно)

Дедлайн = настройка `daily_mark_deadline` (по умолчанию 22:00, см. [[22 - Настройки приложения]]):

| Когда (для даты D) | Что можно |
|---|---|
| до 22:00 в D−1 | всё: «Работаю»/«Выходной», объём, время, точка, туда-обратно — сколько угодно раз |
| 22:00–00:00 D−1 | только время и точку; объём, отмена и статус — нельзя; записаться на D нельзя |
| с 00:00 D | ничего, кроме срочной записи «на сегодня» (`awaiting_approval`, решает админ) |

После ограничения — кнопка «Связаться с администратором»: сообщение уходит владельцам/админам/тренеру сети,
смена не меняется (`contact_admin`). Все проверки на сервере (`phase()`, `mark_deadline()`, `clock()`).
`edit_window_closed` — ручная правка админа закрывает свободное окно. После сдачи отчёта сотрудник сам меняет/отменяет
смену не может (`_require_no_report`).

## Идемпотентность и журнал

Каждая мутация — одна транзакция + уникальный `idempotency_key` (в `event_logs`). Повторное нажатие кнопки,
повтор запроса — не создают дубликат. `log_event()` пишет old→new. API-обёртки: `POST /api/shifts/create`,
`PATCH /api/shifts/{id}`, `/cancel`, `/restore`, `/pre-declare-off`, `/clear-off`, `/contact-admin` ([[18 - API справочник]]).

## Статусы «Работаю/Не работаю»

`set_work_status`: «Не работаю» закрывает запись (`require_working`), смены, новые выполнения «Алисы», заявки в события;
отменить свою смену и сдать отчёт за отработанную — можно. Напоминания не идут (см. [[17 - Уведомления и планировщик]]).
**18.11:** тумблер переключают только начальники — инструктор своим людям, тренер своей сети, админ/владелец любому
(`svc.set_work_status` проверяет `manages(actor, target)`); сам сотрудник переключить не может, персонал — свой статус может.

## Срочные заявки

`create_shift(is_urgent=True)` на сегодня → `awaiting_approval`; админам в бот кнопки «Разрешить/Запределить»
(`decide_urgent`). Не решённая до конца дня закрывается сама (`expire_urgent` в планировщике).

## Распред

`svc.raspred(conn, day, actor)` — текст на день (сегодня/завтра/любая дата) для копирования в рабочий чат.
Тренер видит только свою сеть. В боте: `/raspred_zavtra` и кнопка; в админке «Распред» + автозадача 21:00.
Стажёры помечены «стажёр», учебные смены не считаются работой. Смена без времени печатается «время уточняется»,
без объёма — без штук; общий объём дня считается по сменам, где он есть (24.11).

## Неделя и история

- `week_view(conn, user, offset)` — неделя пн–вс: карточки дней со статусами, коллеги на точке (если `show_colleague_names`).
- `history()` — история смен со всеми деталями (штрафы через `_shift_fines` — из журнала финансов).
- `admin_mark_day` — «День»: админ ставит человеку «Выходной» или «В график» на сегодня/завтра ([[18 - API справочник]], `POST /api/admin/day/{day}/mark`).

## Участники и точки

`points` — справочник точек с лимитом людей на день; если заданы, сотрудник выбирает из списка и видит занятые места.
`day_totals`, `shifts_on`, `active_shifts_on` — агрегации дня (план/факт).

## Точка: кто её выбирает (24.11)

Три механизма вокруг одного поля `shifts.location`, все на существующих сменах и точках.

### «Запретить самостоятельно выбирать точку» (настройка, [[22 - Настройки приложения]])

Тумблер в «Настройках» (`shift_point_locked`, ставят владелец/админ). Включён — у **сотрудников** (`role = employee`
без гранта, `svc.point_locked_for`) форма смены не показывает выбор точки и подписывает «Выбор точки недоступен: точку
назначит ваш тренер/инструктор»: на день записаться можно — **без точки** (`location` NULL; раньше пустая точка давала 422
`bad_location`). Назвать точку самому — 403 `point_locked`. Изменяя смену или возвращаясь в график, сотрудник точку не
трогает: прислал пустую — остаётся назначенная, прислал другую — 403 (`_guard_point_lock`). На руководителей и все экраны
админки не действует. Приходит в `GET /api/me` → `pricing.point_locked`.

### «Распределение по точкам» (раздел «Смены», `assign.py`)

Руководитель ставит человека на точку за дату: дата → люди → точка → «Назначить» (`POST /api/admin/assign`).
- записи нет — создаётся `active`-смена **одной точкой** (`start_time/end_time/volume` NULL, «время уточняется»; учебная
  для стажёра — по обычному правилу), время и объём потом вписывают в «Дне» или в самой карточке смены;
- смена без точки — точка ставится; другая точка — заменяется (клиент спрашивает подтверждение); «Снять точку» — убирает;
- та же точка — `changed: false`; повтор с тем же ключом — ничего не делает;
- выходной и отменённая смена правятся в «Дне» (409 `day_off` / `cancelled`), прошедший день — 409 `past_date`,
  вместимость точки — как всегда (`check_point`, 409 `point_full`);
- кто кого: `assign.may_assign` ([[03 - Роли и права]]); при назначении **ничего никому не отправляется** —
  уведомление только кнопкой «Отправить график» ([[16 - Рассылки]]).

Смена без времени/объёма безопасна везде: распред печатает «время уточняется», суммирование объёма не падает
(`raspred`, `stats`, `export`), напоминание накануне и служебные тексты сходят с уведомлениями без времени и точки.
Отчёт по смене без времени сдать нельзя («Смена не состоялась») — факт вносится, когда время и объём проставлены.

### «Надбавка за точку»

Надбавка — **бонус, не ставка**: редактируется в «Настройки → Точки» (`points.bonus`), начисляется сама при принятии
отчёта. Правила и расчёт — [[06 - Финансы, ставки и вычеты]].
