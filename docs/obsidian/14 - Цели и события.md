# Цели и события

**Обновлено:** 2026-11-17 · **Исходники:** `backend/app/goals.py`, `backend/app/events.py`, `backend/app/lifecycle.py`

## Цели (goals.py)

Прогресс = **принятые** отчёты за период (включая авто- и командные); считается запросом, не накапливается: цель,
созданная в середине, сразу учитывает принятые отчёты с начала периода; отчёт не считается дважды. «На проверке» — отдельно.

| Вид | Кто ставит | Участие |
|---|---|---|
| `personal` | владелец/админ — любому; тренер — своим | автоматически |
| `team` | владелец/админ | «🙋 Участвую» |
| `network` | владелец/админ; тренер — своей сети | люди сети |
| `group` | галочками; тренер — только своих | автоматически |
| `point` | владелец/админ (нужны точки) | у кого смена на точке; факты дня суммируются (принятые + на проверке + правки админа); день обнуляется в `reset_time`; `forever` — «каждый день, пока не изменят»; выполнили норму — уведомление раз в день (`goal_days`) |

`mode`: shared (общая норма — объёмы складываются) / each (норма каждому). Приз — тип (деньги/подарок/сертификат/выходной/мерч/свой)
+ описание + фото. `product` — считать принятые выполнения продукта ([[13 - Работа, Алиса и Яндекс Плюс]]); можно
«Выдать доступ и создать». Выполненные — ✅, уведомления участникам и автору.

## События (events.py)

Таймер, приз (фото или видео до 50 МБ), живой рейтинг (обновление 5 сек):

- **Гонка до цели** (`first_to_reach`): заявка = число ≥ цели + скриншот; проверяющие подтверждают победителей по порядку (👑);
  лимит победителей достигнут → событие завершено, итоги всем.
- **Кто больше** (`accumulative`): подтверждённые заявки суммируются; рейтинг = подтверждено + на проверке (светлая часть);
  призы по подтверждённому, при равенстве раньше набравший; после таймера `buffer_min` (15 мин) на проверку, затем итоги.

Одна заявка на проверке за раз; отклонение только с причиной (участник видит её и номер попытки); после `max_attempts`
отклонений участие закрыто. Тренер — события своей сети и проверка заявок своих. Заявки приходят в бот со скриншотом и
кнопкой «🏁 Проверить в приложении» → «Админ → События» с подсвеченной заявкой; решает первый, карточки у всех проверяющих
поминаются («✅ Подтверждено — кто» / «❌ Отклонено — кто, причина»; опоздавший видит «Уже решено»). Вкладка «События» у
сотрудников — пока есть активное или недавно завершённое.

## Правка, скрытие, архив (lifecycle.py — общее для целей и событий)

- **Кто правит**: владелец/админ — любые; тренер — свои и в своей сети. Оптимистичная блокировка: PATCH несёт `version`,
  устаревший → 409 «Данные устарены».
- Важные поля (даты, норма/цель, победители/попытки, приз и тип) → вопрос «Уведомить участников?» → «⚠️ Важное обновление»
  что было → что стало. Название/описание/фото — молча. Норму снизили → дотянувшим «выполнено»; подняли → «выполнено» само
  не снимается, есть «Снять выполнение»; «Аннулировать результат» участника — с причиной, объём перестаёт учитываться.
- События: старт только до начала; у гонки с победителями цель не меняется; «Отменить результат» — результат не считается,
  попытка не сгорает; финиш в прошлом → завершение и итоги; финиш позже у завершённого → «Перезапустить».
- **Видимость**: `auto` (в ленте, через `feed_hide_after_days` дней после конца → «Архив»), `shown` (закреплено), `hidden`
  (скрыто: заявок нет, к цели не присоединиться, итоги сохраняются). 👁 — переключатель с подтверждением.
- **🗑 Удалить** — soft (`deleted_at`): пропадает у всех и из архива, запись в БД остаётся.
- Архив у сотрудника: «Профиль → Архив целей и событий» и ссылка внизу «Событий».
