# Инфраструктура и деплой

**Обновлено:** 2026-11-18 · **Исходники:** `Dockerfile`, `docker-compose.yml`, `Caddyfile`, `deploy/install.sh`, `deploy/owners.sh`, `deploy/token.sh`, `backend/scripts/backup.py`

## Сервер и пути

> [!warning] Из AGENTS.md (жёсткие запреты)
> - Рабочая копия для разработки — эта папка. **Боевая установка `/opt/bot_sanya`**: её файлы, `.env`, `data/` и контейнеры не трогать.
> - Не запускать `docker compose` в `/opt/bot_sanya`, не останавливать боевого бота, не трогать чужие контейнеры/образы.
> - Секреты (токен бота, ADMIN_IDS, токены GitHub/DuckDNS, ключи API) живут только в `/opt/bot_sanya/.env`; никогда не коммитить и не выводить.
> - Агент работает под root на сервере, рабочая копия — `/root/bot_sanya`. Docker на сервере — только одноразовые контейнеры для проверок (`python:3.13-slim` для pytest, `node:22` для lint), т.к. там Python 3.14 и нет Node.

## Образ и контейнеры

- `Dockerfile`: стадия 1 `node:22-alpine` — `npm ci && npm run build` (static export); стадия 2 `python:3.13-slim` —
  `pip install -r backend/requirements.txt`, копия backend + `frontend/out`, `ENV DB_PATH=/data/bot.db MEDIA_DIR=/data/media
  FRONTEND_DIST=/app/frontend/out PORT=8000`, `CMD python -m app.main` из `/app/backend`.
- `docker-compose.yml`: сервис `app` (env_file `.env`, том `./data:/data`, restart unless-stopped) + `caddy:2.8`
  (порты 80/443, том `Caddyfile:ro` + `caddy_data`, Let's Encrypt для `$DOMAIN`, `reverse_proxy app:8000`).

## Установка и обновление

```bash
bash deploy/install.sh    # под root: проверка доступа к Telegram, swap, Docker, вопрос токена и админов, сборка, запуск, ежедневный бэкап
```
Повторный запуск обновляет до свежей версии ветки. `.env` и база сохраняются. Вручную: `.env.example → .env`, `docker compose up -d --build`.
Без домена — бесплатный `<ip>.sslip.io`. Бэкап руками: `docker compose exec app python scripts/backup.py /data/backups`.

## Владельцы и токен

```bash
bash deploy/owners.sh                    # показать владельцев
bash deploy/owners.sh add|remove <TG_ID> # изменить ADMIN_IDS (последнего убрать нельзя), перезапуск
bash deploy/token.sh [check]             # сменить токен бота (скрытый ввод, проверка в Telegram, .env.bak) / показать подключённого бота
```

## Локальная разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements-dev.txt
cd backend && ../.venv/bin/python -m pytest
BOT_TOKEN=… ADMIN_IDS=… RUN_BOT=0 ../.venv/bin/python -m app.main   # API без Telegram
cd frontend && npm install && npm run dev   # :3000, /api → :8000
```
