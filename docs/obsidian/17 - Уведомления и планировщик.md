# Уведомления, медиа и планировщик

**Обновлено:** 2026-11-19 · **Исходники:** `backend/app/notify.py`, `backend/app/digest.py`, `backend/app/jobs.py`, `backend/app/media.py`, `backend/app/export.py`

## Notifier (notify.py)

Все сообщения бота строит `Notifier` из БД **в момент отправки** (суммы всегда актуальны). Отправка фоновая
(`notifier.spawn(...)` — API не ждёт). Особенности:

- Устойчивость к лимитам Telegram: обработка `TelegramRetryAfter`/сетевых ошибок, повторы.
- Профили-ссылки: один механизм `person_link` (с username — `t.me/`; без — карточка в чат с ботом: ID + «Копировать»,
  «Прислать карточку», «Открыть профиль», если приватность разрешает; иначе честное «профиль скрыт»).
- Ссылки в приложение: `app_link(...)` — глубокие ссылки (например, `open=events,entry=N` для «Проверить в приложении»).
- Архивная группа (`/archive_here`, `archive_off`): деньги/статусы/дисциплина с хештегами (`#штраф #блок #пауза #роль
  #доступ #выплата #нарушение #отчёт`, тег сотрудника `#Иван_Петров`); каждая запись дублируется в `archive_log`,
  неудавшиеся видны с причиной.
- Заблокированным ничего не отправляется; «Не работаю» не получают напоминания.
- `send(..., silent=True)` — сообщение без звука/вибрации (`disable_notification`).

## Сводка служебных уведомлений (digest.py, 19.11)

Служебные уведомления руководству («встал в график», «взял выходной», правки смен, заявки на изменение профиля,
этапы стажировки, итоги общего факта, вердикты отчётов другим проверяющим) можно **группировать в одну сводку**
вместо пинга на каждое событие. Настройки — «Админ → Настройки → Служебные уведомления»:

- **Группировать в сводку** (`staff_digest_enabled`) — уведомления пишутся в очередь `notify_queue`
  (миграция 47, категория + текст), планировщик раз в `staff_digest_every_min` (15 мин … сутки) шлёт каждому чату
  одно сообщение «🔔 Сводка — ДД.ММ ЧЧ:МСК» с пунктами по разделам (🗓 График, 📝 Отчёты, 💰 Деньги, 👥 Команда,
  🎓 Онбординг, 📊 Общий факт); длинная сводка продолжается следующим сообщением (раздел называется заново).
- **Без звука** (`staff_digest_silent`) — служебные уведомления приходят без звука и вибрации, в обоих режимах.
- **Тихие часы** (`staff_digest_quiet`, с/до — по умолчанию 22:00→09:00, окно может переходить через полночь) —
  ночью сводка только копится и приходит сразу после их окончания; интервал при этом не «сгорает».

Механика: только информационные уведомления без кнопок (`staff_notice`, `category` у `to_admins`/`to_onboarding`/
`to_managers`); карточки, где нужно решение (срочная заявка, финальная отмена, заявка на регистрацию, штрафы,
заявки на штраф) всегда идут мгновенно. Личные сообщения человеку (штрафы, напоминания, рассылки) не трогаются.
В режиме сводки уведомление ставится в очередь **компактной строкой** (`schedule_line` и подобные), в мгновенном
режиме тексты прежние. Выключение настройки осушает очередь (старое не вываливается), записи старше 2 дней
отбрасываются; шапка «продолжение» — для длинных сводок. Ключи — в [[22 - Настройки приложения]].

## Медиа (media.py)

Скриншоты/фото хранит Telegram (`file_id`); сервер — только временное (`temp_path` у «Алисы» до отправки) и видео
рассылок > 20 МБ (`MEDIA_DIR`, `local:` id). Приложение показывает по **короткоживущим подписанным ссылкам**
`/api/media/...?exp=&sig=` (HMAC по виду ресурса: report/tx/violation/event/prize/broadcast/alice/aliceqr/avatar/manualimg) —
`<img>` не умеет слать initData. Загрузка фото из Mini App: RAW-тело до 10 МБ, JPG/PNG/WebP (`media.sniff`).

## Планировщик (jobs.py)

Тик каждые 30 сек. Суточные задания заявляются в `job_runs` ( рестарт не дублирует) и срабатывают только в окне
3 часа от своего времени (простой сервера не рассылает устаревшее). `_every()` — «не чаще N минут» (хранится в app_settings).

| Задание | Когда (по умолч.) | Что делает |
|---|---|---|
| `eve_reminder` | 20:00 | напоминание о завтрашней смене (время, точка, кто ещё) |
| `auto_raspred` | 21:00 | распред на завтра админам |
| `week_reminder` | чт 12:00 | «отметь следующую неделю» тем, кто ничего не отметил |
| `weekly_report` | пн 10:00 | итоги недели + Excel админам |
| `attendance_check` | пн 10:30 | норма выходов → «Дисциплина» |
| `daily_mark_reminder` / `daily_mark_check` | 20:00 / 22:00 | напомнить отметить завтра / создать нарушения «не отметил» |
| `fact_request` | конец смены + 15 мин | запрос отчёта в боте |
| `report_reminder` | за 120 мин до срока | напоминание об отчёте |
| `no_show` | по сроку | смена → неявка, уведомления |
| `report_digest` | 22:00 | сводка админам (аудитория `report_digest_to`: owners/admins/staff) |
| `global_actual_evening/morning` | 21:30 / 09:30 | напоминание владельцу про факт дня |
| `backup` | 04:00 | дамп SQLite файлом владельцам |
| `training_reminder` | накануне 20:00, утро 08:00 | напоминание кандидату об обучении |
| `stage_reached` | по факту | стажёр набрал норму — руководителям |
| `groups_check` / `groups_auto` | 10:15 / каждые 10 мин | сверка групп, авто-приглашения |
| `alice_retry` | каждые 10 мин | повтор отправки невылетевших альбомов |
| `expire_urgent` | по дате | срочная заявка прошедшего дня закрывается |
| `event_finished` | по таймеру | завершение событий + итоги |
| `goals` | по факту | проверка выполнения целей |
| `digest` | каждые `staff_digest_every_min` | сводка служебных уведомлений по чатам (вне тихих часов) |

Время/включение всего — в настройках ([[22 - Настройки приложения]]).

## Excel (export.py)

`export.build_xlsx`: листы «Итоги», «Смены», «Штрафы и бонусы» (по журналу финансов); приходит файлом в бот.
Вызов: `POST /api/admin/export`, недельный отчёт, реестр выплаты.
