# Архитектура и стек

**Обновлено:** 2026-11-17 · **Исходники:** `backend/app/main.py`, `backend/app/config.py`, `backend/app/auth.py`, `backend/app/api.py` (create_app), `Dockerfile`, `docker-compose.yml`, `Caddyfile`

## Что это за приложение

Проект «Иди работай!» (`bot_sanya`): Telegram-бот + Mini App. Функционал: график смен, отчёты с фото, штрафы/бонусы/выплаты, сети тренеров и инструкторов, рекрутинг с анкетой и обучением, цели, живые события, рассылки, продукты «Яндекс Алиса» и «Яндекс Плюс» (фотовыполнения по QR с модерацией), методички, дисциплина.

## Один процесс — три роли

`python -m app.main` (из `backend/`) поднимает в одном asyncio-процессе:

| Роль | Модуль | Что делает |
|---|---|---|
| Telegram-бот | `bot.py` (aiogram 3, long polling) | команды, inline-кнопки, FSM-диалоги (см. [[19 - Telegram-бот]]) |
| REST API + статика | `api.py` (FastAPI/uvicorn, порт 8000) | все `/api/*` + раздача `frontend/out` (см. [[18 - API справочник]]) |
| Планировщик | `jobs.py` `run_scheduler()` | тик каждые 30 сек: напоминания, неявки, бэкап (см. [[17 - Уведомления и планировщик]]) |

Особенности запуска (`main.py`):
- Без `BOT_TOKEN` — SystemExit. `RUN_BOT=0` — только API без Telegram (локальная разработка).
- `setup_menu_button` фоново ставит кнопку меню «Приложение» всем с доступом.
- При падении любой из задач (uvicorn/polling/scheduler) процесс завершается (`asyncio.wait FIRST_COMPLETED` + `t.result()`).

> [!important] Модель конкурентности
> Все DB-вызовы синхронные (sqlite3), транзакции `BEGIN IMMEDIATE` (`db.transaction`). Хендлеры FastAPI —
> всегда `async def` (НЕ `def`, иначе уедут в thread pool и транзакицы будут перехлёстываться).
> Один процесс = один писатель; бэкап-скрипт читает через `sqlite3.Connection.backup`.

## Аутентификация Mini App

`auth.py`: каждый запрос API несёт заголовок `X-Telegram-Init-Data`. Проверка по алгоритму Telegram
(HMAC-SHA256 c ключом `HMAC("WebAppData", bot_token)`), срок жизни `init_data_max_age = 24 ч`.
Невалидно → 401 «Откройте приложение из Telegram». `sign_init_data()` — для тестов.

Зависимости в `api.py`: `tg_user` (подпись) → `current_user` (`ensure_admin`, статус approved, не blocked) →
`staff(capability)` (панель + право, см. [[03 - Роли и права]]).

Фото/медиа в `<img>` не могут слать initData — отдаются короткоживущими подписанными ссылками (`media.py`, см. [[17 - Уведомления и планировщик]]).

## Конфигурация

`config.py` — dataclass `Settings`, читает `.env` из корня (мини-загрузчик, существующие переменные окружения выигрывают):

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота от @BotFather | обязателен |
| `ADMIN_IDS` | Telegram ID владельцев через запятую | обязателен |
| `DOMAIN` | домен Mini App (для Caddy) | — |
| `WEBAPP_URL` | https-адрес Mini App для кнопок | — |
| `TIMEZONE` | часовой пояс дат (Europe/Moscow) | Europe/Moscow |
| `DB_PATH` | файл SQLite (в Docker `/data/bot.db`) | `data/bot.db` |
| `MEDIA_DIR` | медиа-файлы вне Telegram (в Docker `/data/media`) | `data/media` |
| `FRONTEND_DIST` | каталог статики Mini App | `frontend/out` |
| `RUN_BOT` | `0` — не запускать polling | `1` |

Пример — `.env.example` в корне. Секреты живут ТОЛЬКО в `/opt/bot_sanya/.env` на сервере (см. [[21 - Инфраструктура и деплой]]).

## Фронтенд

Next.js 15 + React 19 + shadcn/ui + Tailwind 4, **статический экспорт** в `frontend/out`, отдаётся бэкендом.
Без подписанных initData (вне Telegram) — экран «Откройте из Telegram». Подробно: [[20 - Фронтенд Mini App]].

## Инфраструктура

Docker two-stage (node:22-alpine сборка веба → python:3.13-slim рантайм), `docker-compose.yml` (app + caddy:2.8,
TLS автоматически, `{$DOMAIN}` → `app:8000`), данные в томе `./data → /data`. Развёртывание — [[21 - Инфраструктура и деплой]].
